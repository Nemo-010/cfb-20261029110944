# cfb

Control plane on Cloudflare, payload on your own metal: a spec + tool
catalog for self-hosted replacements of Cloudflare R2, Workers, Durable
Objects, Sandboxes/Containers and CI, with the dashboard/manager hosted
on Cloudflare itself (Workers SPA + Access + Tunnels).

Status: research in progress. See `SPEC.md` and `catalog/` when they land.
